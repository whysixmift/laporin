# Laporin Report Schema (MVP)

The **Report Project** aggregates three fact categories and generated content.

```json
{
  "id": "uuid",
  "title": "string",
  "status": "enum",
  "student": {
    "full_name": "string",
    "student_id": "string",
    "school": "string",
    "major": "string?",
    "semester": "string?"
  },
  "internship": {
    "company_name": "string",
    "company_address": "string?",
    "department": "string?",
    "role": "string?",
    "start_date": "date?",
    "end_date": "date?",
    "company_supervisor": "string?",
    "school_supervisor": "string?",
    "description": "string?"
  },
  "research_facts": [
    {
      "claim": "string",
      "source": {
        "url": "string",
        "title": "string?",
        "fetched_at": "datetime",
        "confidence": 0.0-1.0
      }
    }
  ],
  "generated_sections": {
    "cover": "AI_DERIVED_TEXT",
    "introduction": "AI_DERIVED_TEXT",
    "company_profile": "AI_DERIVED_TEXT",
    "activities": "AI_DERIVED_TEXT",
    "conclusion": "AI_DERIVED_TEXT"
  },
  "metadata": {
    "created_at": "datetime",
    "updated_at": "datetime",
    "version": "integer"
  }
}
```

### Fact Classification Rules
- **USER_FACT**: Any field directly entered by the user (e.g., `student.full_name`). Stored unchanged.
- **RESEARCH_FACT**: Facts generated by the **Research** job, always accompanied by a `source` object.
- **AI_DERIVED_TEXT**: Free‑form prose produced by the **Generation** job; must only reference existing USER_FACT or RESEARCH_FACT.

### Extensibility
- New sections may be added under `generated_sections` without affecting existing templates; the renderer maps keys to placeholders in the DOCX template.
- The schema is versioned (`metadata.version`) to allow future template revisions.

---
> The schema drives the OpenAPI `Report` model, the DB `report_projects` tables, and the DOCX placeholder mapping.
